# Premax Admin Management System (CRM)

The decoupled administrative management panel and CRM powering the backend operations for the Premax Auto Service ecosystem. This dashboard gives administrators, service managers, and technicians full operational oversight over bookings, user accounts, and business performance metrics.

## Tech Stack
* **Frontend:** Vue.js (Vue 3, Component Reusability)
* **Backend Data Management:** PHP / Laravel API Layer
* **Security:** Role-Based Access Control (RBAC)

## Key Features & Architectural Highlights
* **Role-Based Access Control (RBAC):** Implemented a rigorous authentication and authorization layer protecting administrative endpoints, ensuring data isolation between different operational roles.
* **Stateful Tracking Systems:** Engineered responsive reactive dashboards using Vue 3 to provide live state tracking for active garage workflows, vehicle statuses, and incoming scheduling requests.
* **Decoupled Architecture:** Designed to serve as the operational nerve center of a multi-sided ecosystem, consuming secure backend APIs while maintaining complete frontend independence.
* **Data-Dense UI Design:** Built with focus on structural scannability, utilizing clean, complex tables and filters to allow rapid management of heavy transactional data volumes.
